# 🛋️ React Furniture Store

A furniture e-commerce application built with React and JavaScript. The project demonstrates component-based architecture, state management, dynamic product filtering, and shopping cart functionality.

## 🚀 Features

- **Product Catalog** — browse furniture products with images, descriptions, and prices.
- **Category Filtering** — filter products by furniture category.
- **Shopping Cart** — add and remove products from the cart.
- **Total Price Calculation** — automatically calculate the total order amount.
- **Product Details Modal** — click on a product image to view more information.
- **Interactive UI** — hover effects and dynamic interface updates.

## 🛠️ Tech Stack

- React (Class Components)
- JavaScript (ES6+)
- HTML5
- CSS3
- React Icons

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/ARMINEPAL/react-furniture-store.git
```

Navigate to the project directory:

```bash
cd react-furniture-store
```

Install dependencies:

```bash
npm install
```

Start the development server using the script defined in `package.json`.
